GitHub only. Every note is also saved as a real .md file in a folder you choose, so you can work with GitHub and device storage at the same time. Edits you make to these files are uploaded on the next sync.
Your notes are saved as normal .md files in a folder you choose, so they show up in your file manager and other apps (Obsidian, Syncthing…). Edits made outside the app appear after a refresh.
